# Contributing to Valsec

Keep vendor parsers and remediation modules isolated, add normalized fields deliberately, and keep compliance predicates deterministic. Any AI-derived mapping must remain reviewable and cannot become confirmed without operator approval.

Run the focused backend tests, backend compilation, frontend typecheck/build, `docker compose config`, and `git diff --check` before review. Reviewer ownership is defined in [`.github/CODEOWNERS`](.github/CODEOWNERS).
